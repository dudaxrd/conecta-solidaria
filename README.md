# Conecta Solidária

O Conecta Solidária é uma plataforma web desenvolvida para uma ONG do terceiro setor, com o objetivo de conectar pessoas que desejam ajudar a iniciativas que promovem solidariedade e transformação social.

## Sobre o projeto

O projeto apresenta informações sobre a ONG, seus projetos e formas de participação. A aplicação foi desenvolvida priorizando organização, acessibilidade, responsividade e utilização de HTML semântico.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## Funcionalidades

- Navegação entre as páginas da aplicação
- Apresentação dos projetos da ONG
- Formulário para participação
- Menu responsivo
- Validação de formulário
- Recursos de acessibilidade, incluindo navegação por teclado, foco visual e atributos ARIA

## Estrutura do projeto

O projeto está organizado nas seguintes pastas:

- `html/` – páginas HTML da aplicação
- `CSS/` – arquivos de estilização
- `js/` – arquivos JavaScript
- `imagens/` – imagens utilizadas no projeto

## Como executar o projeto

1. Faça o download ou clone este repositório.
2. Abra a pasta do projeto no Visual Studio Code.
3. Abra o arquivo `html/index.html`.
4. Execute o projeto no navegador utilizando a extensão Live Server ou abrindo o arquivo diretamente no navegador.

## Versionamento

O projeto utiliza Git e GitHub para controle de versão. O desenvolvimento foi organizado com branches para separar as alterações antes da integração ao código principal.

Foram utilizados commits para registrar as modificações, além de issues, milestone e pull request para organizar e documentar o desenvolvimento.
